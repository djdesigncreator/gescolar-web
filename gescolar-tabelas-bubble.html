Gescolar — tabelas do Bubble

Versão do servidor 5.6.3 · 23 tabelas · 228 campos. Marque cada campo à medida que confirma.

Regras
1. Escola é a única ligação (tipo Escola). Todos os outros ids são text.
2. text (lista) = tipo text com This field is a list (multiple entries) marcado.
3. Datas no formato AAAA-MM-DD (Data da Chamada, Falta, Aula Pratica, Exame, Diario) são text; as outras datas são date.
4. Todas as tabelas marcadas em Settings → API → Enable Data API.
5. Se um campo existir com o tipo errado: mudar o nome para "… antigo", apagar e criar de novo.
